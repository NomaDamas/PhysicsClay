# PhysicsClay 사용 가이드

[English](USAGE.md) · 한국어

PhysicsClay에서는 시뮬레이션 로봇에게 사람한테 하듯 일을 시킵니다. **말하고, 가리키고, 보여 주면** 됩니다.
로봇은 움직이기 전에 계획부터 보여 주고, 사용자는 "go"라고 하거나 틀린 부분만 고칩니다.
앱 상단 바의 **Help**(**?**) 버튼을 누르면 이 가이드의 요약본이 열립니다(English / 한국어 전환 가능).

## 빠른 시작

macOS 또는 Linux, 그리고 [uv](https://docs.astral.sh/uv/), git, curl이 필요합니다.

```bash
git clone https://github.com/NomaDamas/PhysicsClay && cd PhysicsClay
make setup                  # .venv, 파이썬 의존성, 로봇 모델, MediaPipe 모델
make run ARGS="--https"     # 이 컴퓨터는 http://127.0.0.1:8777, 휴대폰·Quest는 https://<LAN IP>:8443
```

같은 컴퓨터의 Chrome, Edge, Safari에서 **http://127.0.0.1:8777** 을 엽니다. 휴대폰과 Quest용 주소는 터미널에
출력됩니다.

| 하고 싶은 것 | 방법 |
|---|---|
| 노트북에서만 사용 | `make run` 만으로 충분합니다(8777 포트 http, 127.0.0.1에서는 브라우저가 카메라를 허용). |
| 휴대폰 카메라 또는 Quest | `--https` 를 붙이세요. 기본 `make run` 에는 **HTTPS가 없습니다**. 8443 포트, 자체 서명 인증서라 경고를 한 번 수락해야 합니다. |
| 포트 변경 | `make run PORT=9000 ARGS="--https --https-port 9443"` |
| API 키 없음 | 그래도 동작합니다. 오프라인 규칙 파서와 브라우저 음성 인식을 씁니다. 키는 나중에 Settings에서 넣으면 됩니다. |
| 오프라인 데모 두뇌 | `make run ARGS="--https --mock"` (각본 응답과 제스처, 키 불필요) |
| 외부 공개 서버 | `make run ARGS="--https --byok"`: 방문자가 자기 키를 씁니다([SECURITY.md](../SECURITY.md)). |
| 둘러보기 데모 | 상단 바의 **Demo** 를 누르세요. |

## 1분 요약

**Say · Point · Show. 로봇이 제안하고, 사람은 고친다.**

1. **의도를 가장 자연스러운 방식으로 전달합니다.** *무엇을, 왜* 는 말로, *어디* 는 가리켜서, *어떻게* 는 시범으로.
2. **로봇이 계획을 먼저 보여 줍니다.** 아무것도 움직이기 전에 plan card(계획 카드: 단계, 목표, 제약 조건)와 3D 고스트가
   나타납니다. 모든 경유점은 물리적으로 검사됩니다: 도달 거리, 관절 한계, 충돌, 금지 구역, 주변의 사람.
3. **"go"라고 하거나 틀린 곳만 고칩니다.** 못 하는 일이면 이유("13 cm 너무 낮음")와 가장 가까운 대안을 말해 줍니다.

| 영역 | 내용 |
|---|---|
| 상단 바 | 로봇 pill(누르면 **Robot & scene**), Feasible 미터, **Record**, **Demo**, **Help**, **Settings** |
| You(왼쪽) | 내 카메라, **Gestures**, **Show a video**, 대화 기록 |
| Stage(가운데) | 3D 공유 공간 또는 **Robot eye**(로봇 시점). 아래 dock: Talk, 명령 입력창, Stop, More(…), 도구 |
| Robot's plan(오른쪽) | plan card, Watch 카드, 금지 구역 목록, 불러온 팩, 로봇 상태 |

휴대폰 크기 화면에서는 stage가 전체 폭, 카메라는 작은 PiP, plan은 아래에서 올라오는 시트로 바뀝니다.

## 지시하는 세 가지 방법

| 방법 | 하는 법 | 잘 맞는 것 |
|---|---|---|
| **Say**(말하기) | **Space** 나 마이크 버튼을 누르고 말하거나, 명령창에 입력하고 Enter. | 할 일, 제약("천천히", "꽃병 근처에 가지 마") |
| **Point**(가리키기) | **Point** 도구로 3D 테이블을 클릭. **Robot eye** 에서는 탭하면 지점, 드래그하면 경로. 카메라가 켜져 있으면 팔로 가리키며 "저기에 놔". | 어디에, 어느 것 |
| **Show**(보여 주기) | **Show** 도구: 카메라 앞에서 설명하며 시범. **Show a video**: 휴머노이드가 영상을 따라 함. **Watch → Learn**: 동작을 한 번 보여 줌. **Goal**: 최종 상태를 보여 줌. | 방법, 스타일, 타이밍, 결과 |

누가 내 말을 알아듣는지는 Conversation 헤더의 칩에 표시됩니다.

* **LLM agent**(키가 있을 때): 영어·한국어 자유 문장, 여러 단계 작업, 팩 불러오기, 말로 경로 만들기.
* **Offline parser**(키 없음): 자주 쓰는 영어·한국어 표현. [예시 명령](#예시-명령) 참고.
* 어느 두뇌든 항상 로컬에서 먼저 처리: 계획에 대한 "go"/"취소", "which one?" 답변, 금지 구역, 시범 가르치기.

## Plan card (계획 카드)

입력하거나 말하거나 칩을 눌러 내린 동작 명령(옮기기, 뻗기, 경로 따라가기, 스킬 재생)은 **먼저 제안됩니다**.
버튼과 키보드 단축키는 바로 실행됩니다.

| 단계 | 보이는 것 | 할 수 있는 것 |
|---|---|---|
| Proposing(제안) | 의도, 목표 칩, 번호 붙은 단계, 제약 칩, 초록색 판정, 3D 고스트 | **Run** · **Fix** · **Cancel** |
| Needs you(확인 필요) | 질문과 가장 가까운 대안 | 대안 수락 · **Cancel** |
| Can't do this(불가) | 쉬운 말로 된 이유 | **Fix** · **Cancel** |
| Running(실행 중) | 단계 진행 상황 | **Stop** |
| Done / Didn't finish | 결과와 이유 | **OK** |

* **Run**: 버튼을 누르거나 "네", "좋아", "가자", "실행해"("go", "yes", "do it")라고 말하거나 *Go on* 제스처.
* **Fix**: 명령창으로 커서가 갑니다. 바꿀 점을 말하거나("왼쪽에 놔"), 새 지점을 가리키거나, 고스트 경로의 틀린 부분을
  끌어서 고칩니다.
* **Cancel**: "아니", "취소"("no", "cancel").
* **Which one?(어느 것?)**: 말이 여러 물체에 해당하면 stage에 번호 칩이 뜹니다. 탭하거나, "두 번째", "빨간 거"라고
  하거나, **1–4** 키를 누르거나, 손으로 가리키세요.
* **Nudge pad**: 작업 중이거나 마커·계획·경로가 있을 때, 화살표로 목표를 2 cm씩 옮기고 속도 버튼으로 속도를 정합니다.
* 스킬 계획에는 빠른 보정 버튼이 붙습니다: Wider · Narrower · Slower · Faster …
* 미리보기 없이 바로 실행하려면: Settings → Agent brain → "Confirm before moving" 해제(agent), 또는 `/?preview=0` 으로 접속.

## Dock 도구

| 도구 | 용도 | 사용법 |
|---|---|---|
| **Point** | *어디* | 3D 테이블의 한 지점을 클릭하면 마커(A–F)가 생깁니다. 그다음 "머그를 저기에 놔", "B에 놔". |
| **Zone** | *여긴 안 돼* | 테이블 위에 사각형을 드래그하면 빨간 금지 구역이 생깁니다. "꽃병 근처에 가지 마"라고 말해도 됩니다. 오른쪽 목록에서 지울 수 있습니다. |
| **Goal** | 결과 보여 주기 | **Arrange in 3D**: 물체의 고스트 복제본을 끌어다 놓고 **Make it so**. **From a photo**: 원하는 배치를 찍은 사진. |
| **Show** | 작업 가르치기 | *Teach by showing* 시작: 카메라 앞에서 작업하며 중요한 점을 말하고 "끝". 로봇이 이해한 단계를 보여 주고, 애매한 점을 되묻고, 시뮬레이션에서 연습합니다. 고친 뒤 스킬로 저장합니다. |
| **Path** | 경로 그리기 | 2–5개 지점을 클릭하면 고스트 그리퍼가 검사된 경로로 이어집니다. 끌어서 조정([궤적 편집](#궤적-편집)). |

일부 로봇에는 **Handover**(두 팔 사이 물건 건네기)와 **Drive**(이동형 베이스: 먼저 가리키고 Drive)가 추가되며, 둘 다
LLM agent에게 요청합니다. 로봇이나 장면은 상단 바의 로봇 pill에서 바꿉니다.

## 3D 화면 조작

| 동작 | 마우스 / 트랙패드 | 터치 |
|---|---|---|
| 회전(orbit) | 드래그 | 한 손가락 드래그 |
| 이동(pan) | 오른쪽 버튼 드래그 | 두 손가락 드래그 |
| 확대·축소(부드럽게) | 휠, 트랙패드 스크롤 | 핀치 |
| 프리셋 | **Stage** · **Orbit** · **Top** · **Side** · **↺**(초기화) | 동일 |

* stage 왼쪽 위 **3D / Robot eye** 로 3D 공유 공간과 로봇 머리 카메라를 전환합니다. 작은 PiP 화면을 눌러도 바뀝니다.
* **Robot eye** 에서는 탭하면 지점 표시, 드래그하면 경로가 그려집니다.

## 궤적 편집

제안된 경로는 튜브를 따라 움직이는 고스트 그리퍼와 번호 핸들로 표시됩니다. **파랑** = 문제없음, **빨강** = 어떤 점이
검사(도달, 충돌, 구역, 안전)에 걸림. 경로는 말(agent), 시범, Robot eye에서 그린 선, Path 도구, VR에서 만들어집니다.

| 하고 싶은 것 | 방법 |
|---|---|
| 점 옮기기 | 핸들을 드래그(수평면 위에서 미끄러짐) |
| 높이 바꾸기 | **Alt**+드래그, 핸들 위에서 휠(한 칸 5 mm, Shift 2 cm), 또는 ↕ 칩 |
| 손목 돌리기 | 점을 선택하고 둘레 링의 손잡이를 드래그 |
| 기울기, 속도, 힘, 그립, 허용 오차 | 점 팝오버의 칩 |
| 키프레임 추가 | **Path** 도구로 2–5개 지점 클릭 |
| 말로 고치기 | "거기 더 높게", "꽃병 근처에서 더 천천히"(LLM agent) |
| 실행 | plan card의 **Run**, 또는 "go" |

점을 선택한 상태의 키보드: 화살표는 화면 방향 기준 1 cm 이동(Shift 5 cm), **PageUp / PageDown** 은 높이,
**[** 와 **]** 는 손목 15° 회전, **Delete** 는 삭제, **Esc** 는 선택 해제.

## Watch 모드

오른쪽 열의 **Watch**(관찰) 카드에서 로봇이 사람이 *하는 행동* 에 반응하게 합니다. 모드 칩을 누르거나 말로
켭니다. 카메라가 필요합니다(또는 팩의 합성 데모).

| 모드 | 로봇이 하는 일 | 예시 |
|---|---|---|
| **Mirror**(따라 하기) | 실시간으로 따라 합니다. G1은 전신을, 로봇 팔은 손을 따라오고, 집게손이나 주먹으로 그리퍼를 닫습니다. | "따라 해" |
| **Learn**(배우기) | 시범을 한 번 녹화합니다. "끝"이면 저장(용접 셀에서는 스킬 추출), "이제 해 봐"면 제안 경로로 반복합니다. | "보고 배워" … "끝" … "이제 해 봐" |
| **Respond**(반응) | "~하면 ~해" 형태의 상시 규칙을 실행합니다. | "When I put my hand out, give me the wrench"(한국어 규칙은 agent) |
| **Assist**(보조) | 손 아래를 따라다니다가 막히면 힘을 제한해서 밀어 줍니다(스팟). | "spot me" |
| **Coach**(코치) | 반복 횟수를 세고 회당 짧은 교정 한마디(깊이, 무릎, 허리, 템포). | "자세 봐 줘" |

* "그만 봐"("stop watching")로 끕니다. 규칙은 Assist, Coach 모드에서도 검사됩니다.
* 카드에는 실시간 판독(동작, 단계, 횟수, 든 도구), 규칙 목록(삭제 가능), 규칙 입력창이 있습니다.
* **AI** 칩은 비전 모델의 한 줄 설명을 추가합니다. 선택 사항이며, 몇 초마다 카메라 프레임을 보내고 서버 키가 필요합니다.
* 자세히: [docs/skills.md](skills.md)

## 카메라와 휴대폰 카메라

카메라는 **기본적으로 꺼져 있습니다**.

**이 컴퓨터의 카메라**

1. **You** 열에서 **Turn on camera** 를 누르고, 브라우저가 물으면 허용합니다.
2. 내 모습이 보이고, 3D stage와 Robot eye의 테이블 건너편에 회색 마네킹(나)이 나타납니다. 이제 로봇이 내가 가리키는
   곳과 하는 행동을 봅니다.

**휴대폰을 카메라로 쓰기**(노트북 카메라로 상체 전체가 안 잡힐 때 유용)

1. 서버를 `--https` 로 실행합니다([빠른 시작](#빠른-시작)).
2. **Use my phone** 을 누르면 QR 코드와 주소 `https://<노트북 LAN IP>:8443/phone` 이 나옵니다.
3. **같은 Wi-Fi** 의 휴대폰으로 QR을 찍거나 주소를 입력합니다.
4. 인증서 경고를 한 번 수락합니다. Safari: **Show Details → visit this website**. Chrome: **Advanced → Proceed**.
5. **Start camera** 를 누르고 허용합니다. 노트북에 "Phone connected · streaming 15 fps"가 뜹니다.
6. 휴대폰을 허리 위 상체가 보이는 곳에 나를 향하게 세워 둡니다.

| 문제 | 해결 |
|---|---|
| 휴대폰에서 페이지가 안 열림 | 서버를 `--https` 로 켰는지, `https://`·8443 포트·터미널에 찍힌 LAN IP인지, 같은 Wi-Fi인지 확인(게스트 망은 기기끼리 막는 경우가 많음). |
| "camera not available (needs https)" | `http://<IP>:8777` 로 연 경우입니다. https 주소를 쓰거나, 노트북 자체에서는 127.0.0.1로 여세요. |
| 권한 거부 | 주소창 자물쇠 아이콘 → 사이트 설정에서 카메라 허용 후 새로고침. macOS는 시스템 설정 → 개인정보 보호 및 보안 → 카메라에서 브라우저도 허용. |
| "No person detected", 제스처가 안 먹힘 | 머리, 어깨, 팔꿈치, 손이 다 보일 때까지 뒤로 물러나고, 카메라를 정면으로 보고, 조명을 밝게. |
| 마네킹이나 가리키는 방향이 어긋남 | 카메라를 정면으로 보고, 화면에 한 사람만 나오게 하세요. |

## 제스처

카메라 아래 **Gestures** 를 누르면 안내 카드가 열립니다. 카메라가 켜져 있고 상체가 보여야 합니다.

| 제스처 | 하는 법 | 결과 |
|---|---|---|
| **Stop** | 두 손을 머리 위로 | 로봇이 멈춤 |
| **Slower** | 허리 앞에서 두 손바닥으로 누르기 | 속도 ×0.7 |
| **Come here** | 한 손으로 이리 오라고 손짓 | 들고 있는 물건과 함께 내 쪽으로 뻗음(작업 중이면 목표를 4 cm 당김) |
| **Go on** | 엄지 척, 또는 손바닥을 앞으로 내밀기 | 제안된 계획 확정 또는 재개 |

* 정지 제스처는 0.5초쯤(0.5–0.7 s) 가만히 유지하세요. 손짓(Come here)은 움직임으로 인식합니다.
* 인식된 제스처는 카메라 위 칩에 표시됩니다. 한 번 실행되면, 다시 하려면 손을 내렸다가 다시 하세요.
* 가이드 데모, 시범 가르치기, 영상 따라 하기, Mirror 중에는 쉽니다. **Mock AI** 가 켜져 있으면 Stop은 mock 두뇌가 처리합니다.

## 데모 팩

| 팩 | 로봇 | 내용 | 해 볼 말 |
|---|---|---|---|
| **Weld cell**(용접 셀, `weld_cell`) | MIG 토치를 단 UR5e(또는 Panda) | 직선 이음매와 L자 이음매가 있는 강판 맞대기 이음 두 개. 손으로 위빙을 보여 주면 그 스타일로 용접하고, 토치 끝이 지나간 길을 따라 비드가 자랍니다. 아크 물리는 없습니다. | "보고 배워" … "끝", "조금 넓게", "좋아", "now weld the L seam like that" |
| **Gym**(헬스장, `gym`) | G1(또는 Apollo) | 벤치와 20 kg 바벨. 스쿼트를 세고 자세를 교정하며, 리프트를 스팟합니다. | "자세 봐 줘", "spot me", "help me earlier" |
| **Workshop helper**(작업장 도우미, `workshop`) | G1(물건을 집는 로봇이면 아무거나) | 거치대에 꽂힌 렌치, 드라이버, 브러시. 상시 규칙으로 렌치를 건네줍니다. | 테이블 위로 편 손을 내밀기 |

불러오는 법:

1. 상단 바의 로봇 pill → **Robot & scene** → **Scene** 탭 → **Demo packs**. (More(…) → **Robot & scene…** 은 Scene 탭을 바로 엽니다.)
2. 또는 "용접 셀 준비해 줘", "set up a weld cell"이라고 말합니다(LLM agent).
3. 오른쪽 팩 카드에 해 볼 말과 **No camera? Play a demo**(합성 사람 재생) 버튼이 있습니다.

다른 장면 템플릿을 고르면 팩에서 빠집니다. 자세히: [docs/packs.md](packs.md), [docs/skills.md](skills.md)

## 데이터셋 녹화

1. 상단 바 **Record** → 데이터셋 이름 입력 → **Start**. `REC · 0 ep` 가 표시됩니다.
2. 평소처럼 로봇에게 지시합니다. 움직이기 시작한 작업 하나가 완료·실패할 때까지 에피소드 하나입니다. 움직이기 전에
   거절된 작업은 개수만 세고 녹화하지 않습니다.
3. **Discard last** 는 잘못 찍은 마지막 에피소드를 삭제합니다. **Stop** 으로 녹화를 끝냅니다(진행 중인 작업은 버림).

결과물: `datasets/<name>/<robot>/` 의 LeRobot v2.1 형식. 관절 상태, 액션, 정면·손목 카메라 영상(256×256, 30 Hz),
작업 설명으로 쓰인 내 말, 성공 여부, 내 자세. `pyarrow`(`make setup` 이 설치)와 `ffmpeg` 가 필요합니다.
형식과 헤드리스 대량 생성: [docs/datasets.md](datasets.md)

## VR / MR (Quest)

1. `make run ARGS="--https"`. 터미널에 `https://<LAN IP>:8443` 이 적힌 `Quest :` 줄이 나옵니다.
2. Quest를 같은 Wi-Fi에 연결 → Quest 브라우저 → 그 주소 → **Advanced → Proceed** 한 번.
3. **3D / Robot eye** 옆의 **Enter VR** 또는 **Enter MR** 을 누릅니다. 손 추적(MR은 공간 데이터도)을 허용합니다.

| 헤드셋에서 | 손 | 컨트롤러 |
|---|---|---|
| 경로 그리기 | 집게손(엄지+검지)으로 잡고 이동 | 트리거를 누른 채 이동 |
| 키프레임 추가 | 빈 공간에서 짧게 집기 | 트리거를 짧게 |
| 점 옮기기, 손목 돌리기 | 핸들을 집고 옮기며 손을 비틀기 | 핸들에서 트리거 |
| 로봇 손 실시간 조종 | 주먹 쥐기(집게로 그리퍼 닫기) | 그립 버튼 유지 |
| 메뉴 | 왼손 바닥을 내 쪽으로 | 왼쪽 컨트롤러 |

* **MR**: 실제 테이블의 앞쪽 왼쪽 모서리, 이어서 앞쪽 오른쪽 모서리를 집으면 로봇이 내 테이블 위에 섭니다.
  **Scan → Use my room** 은 테이블 위 물건을 장애물로 바꿉니다.
* 메뉴의 **Go** 나 "go" 전에는 아무것도 실행되지 않습니다. VR에서도 안전 기능이 그대로 적용됩니다.
* 인증서 없이 쓰려면: USB 연결 후 `adb reverse tcp:8777 tcp:8777`, 그리고 `http://localhost:8777`.
  전체 가이드: [docs/vr.md](vr.md)

## 안전

사람 근처에서 로봇이 하는 일:

* 몸의 어느 부분이든 로봇의 어느 부분과 약 50 cm 안에 들어오면 **속도를 줄입니다**.
* 닿기 전에 **멈춥니다**. 머리, 목, 몸통 근처에서는 더 일찍 멈춥니다. 작업은 쉬운 말("Paused for safety: you're 9 cm
  from my gripper")과 함께 일시정지하고, 물러나서 1초쯤 지나면 **스스로 재개합니다**.
* 목표가 사람 몸 영역 안에 있는 뻗기·집기는 계획하지 않습니다. 머리, 목, 몸통에는 어떤 모드에서도 닿지 않습니다.
* Assist, Mirror, 건네주기 중에는 손이 가까이 와도 되지만 아주 느리게 움직이고, 건네줄 때는 손 10 cm 앞에서 멈춥니다.
* 3D에 내 안전 윤곽(주황 = 감속, 빨강 = 정지)과 plan card 위 한 줄 메시지로 보여 줍니다. 힘 한계로 멈춘 경우에는
  물러난 뒤 **I'm clear** 를 눌러야 합니다.
* 앱에서도 설정 파일에서도 **끌 수 없습니다**.
* **인증된 안전 시스템이 아닙니다.** 실제 로봇의 안전 장치로 절대 쓰지 마세요. 자세히: [docs/safety.md](safety.md)

## 음성과 언어

* **Talk**: **Space** 또는 마이크. Gemini API 키(Settings → AI)가 있으면 Gemini Live와 실시간 음성 대화를 하고,
  "Send my camera to Gemini"가 켜져 있으면 카메라도 함께 봅니다. 키가 없으면 브라우저 음성 인식(Chrome, Edge, Safari)을
  쓰고, 언어는 Settings → AI → **Speech language** 를 따릅니다.
* **언어**: 영어와 한국어 모두 됩니다. LLM agent와 Gemini Live는 사용자가 쓴 언어로 답하고, 오프라인 파서의 답은
  영어입니다.
* **로봇 목소리**: Settings → **Voice** 에서 영어와 한국어 목소리를 각각 고르고 **Test** 로 들어 봅니다. OpenAI 키
  (Settings → AI)가 있으면 자연스러운 OpenAI 음성을, 없으면 브라우저나 OS의 가장 좋은 음성을 씁니다.
* **더 좋은 시스템 음성**: macOS는 시스템 설정 → 손쉬운 사용 → 읽기 및 말하기(Spoken Content) → 시스템 음성 →
  음성 관리에서 한국어 **Yuna (Premium)**, 영어 **Ava (Premium)** / **Zoe (Premium)** 를 설치하세요. Chrome에서는
  "Google 한국어", "Google US English"가 좋습니다.

## Settings (설정)

상단 바의 **Settings**(톱니바퀴)를 누릅니다.

| 섹션 | 내용 |
|---|---|
| Appearance | System / Light / Dark |
| Voice | 언어별 로봇 목소리, Test |
| Robot | G1 humanoid 또는 UR5e arm(모든 로봇과 장면은 로봇 pill에서) |
| Camera | 이 기기의 카메라 사용, 전면/후면 전환 |
| Skills | 배운 스킬 재생, 시간 구간 편집(빠르게, 느리게, 크게, 작게) |
| Spatial model | 카메라 속 물체 인식(YOLO segmentation, MediaPipe, Off), Gemini Robotics-ER에 묻기 |
| AI | Gemini API 키, OpenAI API 키(로봇 목소리), 모델, Gemini에 보낼 것, Mock AI, 음성 인식 언어 |
| Agent brain | LLM agent 사용, 움직이기 전 확인. `--byok` 서버에서는 내 LLM base URL, 키, 모델 |
| Demo | 전체 데모, text vs spatial, teach 데모, 데모 중지 |

**키 관리(BYOK, 자기 키 사용)**

* Settings에 넣은 키는 **이 브라우저에만** 저장되고, 그 키가 필요한 요청에만 실려 갑니다.
* 내 컴퓨터에서는 서버 키를 `.env`(git에서 제외됨)에 넣을 수 있습니다: `GEMINI_API_KEY`, `OPENAI_API_KEY`, agent용
  `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`(OpenAI 호환 Responses API면 무엇이든).
* `--byok` 로 띄운 서버는 자기 키를 절대 쓰지 않고, 방문자가 각자 키를 넣습니다. [SECURITY.md](../SECURITY.md) 참고.

## 키보드 단축키

| 키 | 동작 |
|---|---|
| Space | Talk: 듣기 시작 / 중지 |
| Esc | 로봇 정지(경로 점이 선택돼 있으면 먼저 선택 해제, 열린 패널은 닫기) |
| / | 명령창으로 이동(Esc로 빠져나옴) |
| Enter | 입력한 명령 보내기 |
| F | 그린 경로 실행 |
| C | 마커와 그린 경로 지우기 |

| Alt+드래그, 휠 | 핸들 높이 바꾸기 |

입력창에서 타이핑하는 동안에는 단축키가 동작하지 않습니다.

## 문제 해결

| 문제 | 해결 |
|---|---|
| 로봇 pill이 "connecting"에서 안 바뀜 | 서버가 꺼졌거나 재시작된 상태입니다. 터미널을 확인하고 페이지를 새로고침하세요. |
| "I didn't catch an action" | 오프라인 파서가 못 알아들은 것입니다. [예시](#예시-명령)처럼 바꿔 말하거나, LLM 키를 넣으세요(Settings → Agent brain 또는 `.env`). |
| Talk가 반응 없음 | 사이트의 마이크 권한을 허용하세요. Gemini 키가 없으면 Chrome, Edge, Safari를 쓰세요. 휴대폰은 https 주소로. |
| 휴대폰이나 Quest가 접속 안 됨 | `--https` 로 실행, 같은 Wi-Fi에서 `https://<LAN IP>:8443`, 인증서 경고 한 번 수락. |
| 나를 못 보거나 제스처가 안 먹힘 | 상체와 손이 다 보이게 물러나고, 조명을 밝히고, 제스처를 가만히 유지. 데모, 가르치기, Mirror 중에는 제스처가 쉽니다. |
| plan card에 "Can't do this" | 이유를 읽고, 제시된 대안을 고르거나 **Fix**, 장애물을 피하는 경로를 그리거나 장애물을 먼저 치우세요. |
| 로봇이 멈춰서 기다림 | 안전 정지입니다. 물러나면 스스로 재개합니다. 힘 한계 정지 후에는 **I'm clear** 를 누르세요. |
| 3D stage가 비어 있거나 느림 | 3D stage는 CDN에서 three.js를 받아 오고(인터넷 필요) WebGL이 필요합니다. G1은 무거우니 UR5e나 Panda로 바꿔 보세요. |
